# 安装与复用约定

> 历史方案：以下是 2026-09-27 三角色方案的草案接口，不是当前产品安装步骤或实施授权。当前产品支持独立选择云识别与翻译开关，不能套用下文的本地双模型前置条件。版本边界及源码文档入口见 [部署说明](README.md)。

**当前为部署骨架。** 尚无可运行产品二进制、安装器主体、安装校验器或容器镜像。下面定义正式发行需要实现的使用方式；命令是未来接口示例，当前不构成可用安装步骤。

## 1. 选择产品

| 需求 | 产品 | 模型放置位置 |
| --- | --- | --- |
| 当前电脑完成全部字幕流程 | `synesthesia-full` | 本机运行目录的 `models/` |
| 专门提供计算能力 | `synesthesia-server` | 服务端运行目录或容器模型挂载目录 |
| 在当前桌面显示远端计算的字幕 | `synesthesia-client` | 无需模型 |

全功能版和客户端在用户桌面采音，服务端处理客户端上传的音频。跨机器使用时需要可达的服务地址。

## 2. 安装前准备

- 下载对应产品、平台、架构和版本的本项目发行包。
- 核对发行校验和及软件依赖清单；固定版本不因下载地址内容变化而自动接受新文件。
- 选择用户有写权限的便携目录，例如 `D:\software\synesthesia-full`。
- 计算端确认 CPU/GPU 后端的驱动与运行条件；客户端确认音频捕获与窗口权限。
- 模型由用户手动获取，核对来源、许可、兼容性与哈希，并保留原文件名。

默认不修改系统 PATH，不安装全局 Python、Conda、CUDA/Vulkan 开发工具链。必要运行库是否 app-local 分发，应以自主程序和所选依赖的实际需要为准；许可与签名验证同时完成。

## 3. 安装器行为

计划接口：

```powershell
.\install.bat -Product full -InstallDirectory 'D:\software\synesthesia-full' -Plan
.\install.bat -Product server -InstallDirectory 'D:\software\synesthesia-server'
.\install.bat -Product client -InstallDirectory 'D:\software\synesthesia-client'
```

`-Plan` 只报告角色、资产、目标目录和缺失条件，不下载、不创建安装目录。其余安装流程必须满足：

1. 检查目标目录、权限、平台与资产清单。
2. 优先复用已验证缓存；下载到 `.partial` 后校验再使用。
3. 在目标目录同一父目录内创建专属临时构建目录，路径受严格校验。
4. 组装自主构建的程序、必要私有依赖、默认配置、许可和启动工具。
5. 生成管理标记及程序文件清单，完成对应角色的软件验收。
6. 清理构建临时文件，再发布目标目录。失败只清理本次受管理的临时目录。

新目录或空目录可作为安装目标；已有且未管理的非空目录拒绝接管。同版本受管理目录重复安装只校验程序文件并保留用户配置、模型与数据。其他版本应安装到新目录，不静默升级。

## 4. 模型与计算资源

当前规则：安装器不包含、不自动下载、不复制、不打包模型。用户自行将模型放入计算端的 `models/`，通过相对路径配置。候选模型与清单形式见 `assets.example.json`；这不是已经锁定的新产品模型组合。

计划校验入口：

```powershell
.\app\verify-install.ps1 -CheckModels
```

客户端跳过模型验收。计算端缺模型时列出缺少的具体文件并说明处理方式，不自动联网。

先枚举硬件与后端，再按已确认的配置选择资源。设备检测成功仅证明枚举能力，实际模型加载与 GPU 推理另行验收。特定 GPU 不可用时明确失败；若产品提供 CPU 回退，必须显示实际回退结果。

## 5. 启动与调试

正式运行目录分别使用 `start-full.bat`、`start-server.bat` 和 `start-client.bat`。

启动器根据自身所在目录定位程序，允许从其他工作目录启动，参数原样转交。应用自行创建必要日志、缓存与临时目录，并明确错误原因。

`start-debug.bat full|server|client` 计划调用调试工具，显示对应进程的日志和退出状态。调试工具未实现时当前骨架会失败退出。

计算端从加载状态进入就绪后才处理会话；客户端展示连接和采音状态。退出时停止采音、关闭连接并释放所属推理任务或辅助进程。

## 6. 离线安装与整目录移动

正式安装将已校验的软件原始文件保存到 `cache/downloads/`。这些文件可以复制到新设备的只读离线缓存，供安装器复用：

```powershell
.\install.bat -Product full -InstallDirectory 'E:\software\synesthesia-full' -CacheDirectory 'E:\software-cache' -Offline
```

离线模式不联网，缺文件或哈希不匹配立即失败，不修改提供的缓存。模型仍由用户独立准备。

完整运行目录在程序关闭后可整体移动。新设备重新确认架构、驱动、GPU、音频设备与权限；绝对路径与旧设备编号不能成为默认运行依赖。客户端移动后还需确认服务地址。

## 7. 升级、回退与卸载

- 软件升级使用新版本目录，先验证，再迁移允许兼容的配置；保留旧目录以便回退。
- 模型升级核对兼容性、来源、许可与校验信息，保留旧模型至验收完成。
- 卸载前退出应用或服务并确认相关进程关闭，再删除对应运行目录。
- 外置模型目录、独立离线缓存和容器数据由用户单独管理，卸载不能默认删除。
- 系统驱动和系统管理的历史记录不属于便携卸载范围。

## 8. 当前使用限制

本目录没有安装成功、双模型推理、窗口功能或 GPU 加速的实测结果。Windows、Linux、macOS 与 Docker 的声明均按产品目标区分于完成状态，具体发行支持矩阵由验证记录产生。
