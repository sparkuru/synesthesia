# 待实现的部署脚本契约

本目录当前只有接口说明。不存在的主体脚本不能被包装成已完成的安装或验收能力。所有参数和配置字段均为拟定接口，开发时与真实程序一起确认。

## install.ps1

| 参数 | 目标行为 |
| --- | --- |
| `-Product full|server|client` | 选择产品；默认值拟为 full |
| `-InstallDirectory PATH` | 默认安装器旁的 `synesthesia-PRODUCT`；不固定盘符 |
| `-CacheDirectory PATH` | 软件缓存来源；只读使用 |
| `-Offline` | 禁止网络；需要指定缓存来源 |
| `-Plan` | 仅报告，不下载或写入 |

实现顺序：清单与路径检查、安装计划、目标所有权检查、软件获取与 SHA256 校验、受限临时目录组装、角色校验、生成管理清单、发布。禁止跳过哈希、接管未知目录或将开发工具链留作默认运行依赖。

正式清单必须 `release_ready=true`；资产版本、来源和 SHA256 不完整时失败。客户端只选自己的程序与必要音频/窗口依赖，不安装推理或模型。

若需要从发行媒体提取运行库，先核对签名与许可，仅在实际依赖需要时分发。提取逻辑独立实现并验证；不假设某版媒体的固定内部结构对所有版本有效。

## verify-install.ps1

| 参数 | 目标行为 |
| --- | --- |
| `-InstallDirectory PATH` | 指定运行目录；安装后可从 app 目录推导根目录 |
| `-FilesOnly` | 仅校验程序文件，不启动推理 |
| `-CheckModels` | 计算端核对模型文件、大小与哈希；客户端明确无需模型 |

读取 `.synesthesia-portable.json`，校验角色、版本及受管理程序文件；清单中的路径不得逃逸运行目录。用户配置、日志与缓存不纳入不可变文件校验。

文件、硬件枚举、模型加载、实际推理和字幕闭环分别报告。不得仅凭退出码零或显卡枚举成功认定完整验收通过。

## build-package.ps1

输入为已经构建的自主程序、角色、版本、平台和已确认的资产清单。输出角色安装器包或便携包、程序文件清单、软件资产清单、许可材料和校验和。

不下载、复制或打包模型。不把开发目录的日志、临时文件、个人路径、密钥或构建缓存放入发行包。

正式发行不使用 `.example` 文件冒充已验证配置。任何模型或依赖组合变动都重新完成兼容性与硬件验证。

## debug-launch.ps1

拟定输入：`-Product full|server|client`。在安装后的 `app/` 中解析运行根目录，启动该角色程序并报告配置位置、日志、资源选择和退出码。

二进制 CLI、日志格式与诊断参数尚未确定，不预填实际不存在的 `--self-test` 或设备参数。日志输出默认避免保存完整音频、敏感字幕或连接凭据。

## 进程与目录契约

- 应用从自身位置解析运行根目录，不依赖调用者工作目录。
- 正常模式分别由对应 `start-*.bat` 启动；这些入口当前仅检查文件并启动进程。
- 是否设置 TEMP/TMP 或后端缓存环境变量由实际运行需求决定；只影响当前进程及子进程。
- 清理操作验证临时路径与所有权，只处理本次创建的构建文件。
- 所有错误以非零退出码结束；安装、验证、调试失败不能显示成功提示。
