## 正式发行的验收矩阵

| 场景 | 必须证明的行为 |
| --- | --- |
| 安装计划 | 无下载、无目录写入，能显示资产与缺失条件 |
| 新目录安装 | 校验后发布，程序与管理清单相符 |
| 未管理非空目录 | 拒绝接管，原有文件不变 |
| 损坏缓存或变动资产 | 拒绝错误哈希，不发布不完整目录 |
| 离线安装 | 无网络请求，仅使用正确缓存，不修改缓存来源 |
| 同版本重复安装 | 校验程序，用户配置、模型和数据保持 |
| 不同版本安装 | 新目录验证，不静默升级原目录 |
| 构建失败 | 原目标不变，清理限定范围的构建临时目录 |
| 路径变化 | 中文、空格、不同盘符与不同工作目录启动 |
| 模型缺失 | 计算端明确列出缺项，客户端不要求模型 |
| 硬件检测 | 区分设备存在、后端可用、模型加载和实际推理 |
| 指定 GPU 不可用 | 明确失败或显式允许的回退，不伪报 GPU 使用 |
| 真实音频闭环 | 系统输出经捕获，显示原文与对应译文 |
| 字幕状态 | 草稿替换、定稿去重、过期译文不能覆盖新文本 |
| 设备切换与静音 | 不混用旧音频，不产生持续无关字幕 |
| 远程会话 | 网络中断反馈、会话隔离、重连不混用旧结果 |
| 过载 | 缓冲有界、积压可见，不无限增加延迟 |
| 退出 | 无所属采音、网络、推理任务或辅助进程残留 |
| Docker | 在声明宿主与后端上就绪、处理会话、正常停止 |

每次真实验证记录产品版本、平台、架构、设备、后端、模型、操作步骤、日志与结论。只有完成实际推理后才能声明 GPU 加速；只有真实输入闭环后才能声明字幕质量与延迟。
