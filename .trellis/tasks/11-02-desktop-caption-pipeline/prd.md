# PRD v2 桌面字幕交付计划

## 目标与授权

按 [产品 PRD v2](../../../prd.md) 交付“独立输入 → 本地/云 ASR → 原文与可选翻译 → 透明字幕”。本任务管理需求映射、阶段顺序与跨阶段验收；具体运行功能由子任务交付。

2026-11-02，用户要求将旧计划整体归档并重新规划，随后明确首个真实验收平台为 Windows 11 x64。此授权覆盖计划迁移与新规划，未批准直接实现全部后续阶段。

## 当前基础

R0 工程基础和整理已提交，见 [1102 归档记录](../archive/2026-11/11-02-rust-repository/prd.md)。现有状态以 [工程状态](../../../docs/status.md) 为准：已具备配置、共享字幕状态、采音/推理组件与历史实验，尚无完整实时应用。

旧 MVP 及 7 个子任务按 superseded 关闭归档。它们的 completed 是归档生命周期状态，不能算作新计划验收；已有组件通过情况与原始证据分别保留。

## 共同要求

- 输入、ASR、翻译分别配置，不能隐式启动未选引擎或静默切换处理方式。
- 共享 core 字幕状态与身份是唯一权威；队列有界，旧会话/清屏后的结果不能复活。
- 每个阶段只声明真实验证的输入、平台、后端和语言组合；配置可解析、纯测试或旧实验均不算新运行能力。
- 保留 schema 1/WS v1 的兼容边界及历史研究；迁移按实际调用链做，不以删除旧模块替代适配。
- 真实凭据来自本机私密来源，不进入计划、示例、日志、字幕存档或提交。根私密 archive 不访问。

## 跨阶段验收

- [ ] R1 单独完成真实设备、服务和窗口验收，并记录版本/平台/语言、识别对照与资源释放。
- [ ] R2–R4 分别完成已批准的实际组合验收，测试覆盖身份、版本、停止与资源预算。
- [ ] 声明支持的组合完成根 PRD AC-09 的 60 分钟运行；质量、延迟和资源门槛由固定基准确定，不能从测试数量推断。
- [ ] 原文显示、可选翻译与设备/后端切换在最终集成中共同满足根 PRD AC-01–AC-11。
- [ ] 发行包只包含已验证功能、必要依赖和许可，安装/退出/回退有可重现证据。
