# 固定样本与基准测量计划

状态：planning。D-02c 样本范围、D-10 分阶段验收策略与 60 分钟持续运行要求均已获用户批准。本文不是已运行的报告，也不代表已取得样本文件或具体发布数值门槛。

## 已批准样本范围与归属

- 英语、日语各固定 10 分钟清晰单人语音，包含短句、长句及静音；两种语言分别选择和报告。
- 多人对白、背景音乐作补充测试；强噪声和重叠语音不设首版质量硬门槛，不用它们替代主基准。
- C2 固定可使用、可复测的来源、文件/hash、总时长、源语言、参考文本与语音边界标注；C6 复用相同版本，不为了通过测试换掉失败片段。
- 受控测试输入/参考资料由测试者明确准备，独立于应用会话记录；应用不录制用户播放内容，不将生成的字幕正文或音频写入日志/缓存/临时文件。

## 测量定义

| 项目 | 方法与应保存的证据 |
| --- | --- |
| 环境身份 | OS/build、硬件、实际推理设备、驱动、引擎 revision、模型及样本 hash；RX 9070 XT 与 CPU 显式选择的结果分别报告 |
| 加载与首轮 | 模型加载时间、第一次推理与预热后分开；工具枚举不代替模型实际使用证据 |
| 草稿及时性 | 标注每句语音开始至首条非空原文草稿到达客户端的时间；不以重绘频率或翻译完成时间代替 |
| 定稿及时性 | 标注句末音频至该句原文定稿到达的时间，包含分句/VAD 等待；长句另记录中途切分与最大等待 |
| 译文及时性 | 原文定稿至对应译文到达的时间；另报告句末至译文的总时间，不将两者混为一项 |
| 统计与吞吐 | 每语种分别报告样本数、p50/p95/最大延迟、失败/超时数、音频队列时长与积压趋势；缺失或失败事件不可从分母中静默删除 |
| 文本质量 | 与参考文本对照，固定规范化/分词规则并报告原文错误统计；译文人工核对核心意思、遗漏、反转、幻觉和语句对应，评价规则随发布门槛锁定 |
| 资源与回收 | 两款模型共同运行的进程/所属引擎内存、实际设备显存峰值、前台独立开销、停止后的模型驻留和退出后的资源/进程状态 |
| 闭环覆盖 | C2 推理适配测量与 C6 full、client/server 端到端测量分开；两台机器时钟不能直接相减，网络路径/客户端环境有记录 |

仅保留样本身份、匿名语句编号、指标、错误类别和质量评价结论；不将应用生成正文当作诊断日志或提供内容导出。人工对照在受控测试环境中完成。

## 已批准 D-10 验收策略

先在用户指定模型、RX 9070 XT 与已批准样本上取得 C2 实测基准，再向用户呈现质量、延迟和资源指标，锁定发布门槛后由 C6/C7 对照验证。
用户批准暂缓具体准确率/时延/内存数值，不是以任何实测结果自动判定通过；未批准门槛不能宣称 MVP 质量/性能已验收或发布就绪。这是发布前门槛，不要求在尚无源码的规划阶段伪造基准，也不阻塞无关模块的开发。
持续运行要求为 60 分钟无崩溃且音频积压不持续增长；C6 对 full 与 client/server 链路分别验证，可循环固定样本，各轮保持句编号/会话边界清晰，记录定期资源与队列指标。
CPU/可选 Linux Docker CPU 路线报告独立结果，不据此承诺与独显相同实时性能；共用数据、字幕与生命周期正确性仍必须满足。
如果实际结果不满足后续批准门槛，报告失败并改进，不能更换指定模型、静默回退设备、删掉失败样本或自行降低门槛。
