# synesthesia MVP：PRD 补全与技术设计

状态：`in_progress / approved`。用户于 2026-09-27 在最终规划摘要后明确要求“开始实现”；7 个实施子任务已创建，主会话按依赖协调交付。

## 目标与价值

把根目录产品 PRD 转为可实施、可验证的计划：一台桌面采集系统播放音频，
经本机或另一设备识别和翻译，在双语悬浮窗口展示。保留 full / server / client 三种产品边界。
本规划任务负责需求收敛、技术设计、开发拆分与验收映射；后续独立交付由子任务承担。

## 已确认背景

- 产品需求来源：[根 PRD](../../../../../docs/history/2026-09-27-prd.md)，包含 FR-01–FR-07 与 AC-01–AC-15。
- [README](../../../../../readme.md) 指定首轮模型对象：`qwen3-asr-1.7b-q4_k.gguf` 用于识别，`Hy-MT2-1.8B-UD-Q3_K_XL.gguf` 用于翻译。[模型基准](research/model-baseline.md) 已确认文件存在并记录实测 SHA256；发行来源、许可和引擎兼容仍待验证。
- 部署已有角色目录、配置草案和脚本接口；没有应用源码、Cargo manifest、可运行镜像或正式安装器。
- Rust、egui/eframe、CrispASR 与 llama.cpp 是根 PRD 候选，尚未完成兼容实验或最终选型。
- 用户提供的验收机已只读确认 Windows 11 IoT 企业版 LTSC build 26100、Ryzen 9 7950X、64 GiB 安装内存与 RX 9070 XT；[硬件基准](research/hardware-baseline.md) 含驱动显存与 Vulkan 枚举，尚无实际推理证据或 Windows 10 实机证据。
- 计算端目标文件位于用户提供的 `E:\tmp\models`；此目录仅为当前验收配置，不是软件默认路径，客户端无需模型。
- 后端/前端规范仍是模板；现有 `00-bootstrap-guidelines` 保留，不以不存在的源码例子填充或宣称完成。
- 本轮开始时根 `prd.md` 已有用户修改，`readme.md` 未跟踪；保留其内容，不提交或覆盖。

## 规划验收标准

- PA-01：本任务的 PRD、design、implement 分别承担需求、技术方案和执行清单，无源码实现冒充完成。
- PA-02：FR-01–FR-07、AC-01–AC-15 均有交付及验证归属，延期项明确保留。
- PA-03：设计覆盖模块依赖、local/remote 数据流、音频与 WS 契约、字幕版本、背压、生命周期、配置与发布边界。
- PA-04：执行计划按依赖顺序划分可独立验收的工作，列出自动验证与真实平台/设备检查。
- PA-05：研究区分仓库事实、外部文档能力与尚未执行的兼容实验；两份上下文清单引用真实存在的资料。
- PA-06：需求收敛与 PRD convergence pass 完成，用户审阅本版摘要并在后续答复明确批准后，才创建/启动对应实施子任务。

产品验收仍以根 PRD 的 AC 为准；本轮文档检查通过不等于字幕产品验收通过。

## 范围外

- 父任务负责协调，不把子任务中尚未验证的应用源码、后端或设备能力当作已完成交付。
- Linux/macOS 桌面、更多语种、多路实时音频、草稿翻译、公网部署/多租户留作后续。
- TLS/WSS 与自动服务发现不纳入首版。
- Windows Docker 部署与容器 GPU 不属于首版；不把 Docker/WSL 作为 Windows 安装或运行前置条件。
- 全局快捷键、开机启动与自动更新不纳入首版。
- 自动源语言检测不纳入首版。
- 音频/字幕持久化、历史内容回看与内容导出不纳入首版。
- 不更改 Trellis runtime、平台设置、模板文件或既有 bootstrap task 状态。
- 未通过产品/发布验收前不宣称 MVP 已完成；提交、归档和外部发布遵循已有授权及对应门槛。
