# R1 麦克风、Fun-ASR 与原文透明字幕

## 目标与授权

在用户确认的 Windows 11 x64 上交付第一条真实链路：麦克风 → Fun-ASR → 透明置顶原文字幕。无需本地 ASR/翻译模型或自建服务器。

本任务来自用户要求重新规划后的 [父计划](../11-02-desktop-caption-pipeline/prd.md)，平台已明确；当前仍为 planning，产品实现需要对本次最终计划的后续确认。

## 依据与现状

依据 [根 PRD](../../../prd.md) FR-01/02/03/05/06/07，以及 FR-04 的“翻译关闭无需引擎或任务”。现有 schema 2 可表达目标组合，旧 Session、采音停止与字幕 final 终态仍有接线限制；现行能力见 [工程状态](../../../docs/status.md)。

R0 的 75 项测试和旧 Windows/GPU 实验是组件基础；本任务尚未进行设备、云识别或原生窗口验收。

## 要求

- R1-01 输入：支持默认及指定麦克风；用户 Start 且云识别就绪后才开始采音。规范化为统一音频格式，保留会话、输入代际和采样时间轴；权限、断开和格式错误可见，不偷偷改采其他设备。
- R1-02 识别：按 schema 2 显式选择 Fun-ASR 的地域、模型与本机密钥环境变量，报告连接和实际就绪状态；结构检查保持无凭据、无设备、无联网副作用。R1 运行时未支持的系统音频、本地 ASR 或开启翻译组合明确失败。
- R1-03 原文：草稿更新替换当前句，按真实协议定稿；迟到/重复/旧会话结果和清屏高水位均由共享状态拒绝。云协议的定稿语义在接线前明确，不能直接在界面修正状态。
- R1-04 显示：真实透明置顶窗口、可移动/调整大小、字号、自动换行、视觉行数控制、清屏和设置/展示模式恢复；保持最新字幕和错误可见。翻译关闭使用仅原文，视觉行数与历史句数独立。
- R1-05 生命周期：Start/Stop/清屏/退出含义清楚，重复操作不创建重复任务。正常 Stop 先停采集，再在有限期限内处理已接收音频和最后结果；故障/超时走取消路径，并反馈结果是否完整。断网后停止上传，用户显式重新开始时创建新会话，不重放旧音频。
- R1-06 边界：不加载模型或构造翻译任务；音频、网络和事件队列有界，过载明确失败；退出释放本应用的采音、连接和任务。诊断不含密钥、音频、字幕正文或厂商原始错误内容。

## 验收

| 编号 | 可观察结果 | 根 PRD 映射 |
| --- | --- | --- |
| R1-AC1 | Windows 11 x64 真实麦克风经所选地域/模型得到原文，固定受控中文样本记录识别对照、时序和版本；不能仅统计事件数 | AC-01 的麦克风/云组合、AC-10 |
| R1-AC2 | 不存在本地模型也能运行，关闭翻译没有翻译加载或任务；结构检查仍无需密钥存在 | AC-03 |
| R1-AC3 | 草稿替换、定稿、清屏、迟到事件和重新开始不重复或复活旧字幕；协议边界用无敏感内容的固定事件夹具覆盖 | AC-04 |
| R1-AC4 | 真实桌面验证透明置顶、移动/调整、字号/换行/视觉行数、设置恢复与可见错误 | AC-06 的本轮范围 |
| R1-AC5 | 正常 Stop 的最后结果得到有界处理，停止后无后续旧会话处理；错误/超时明确提示不完整，退出后无所属资源残留 | AC-07 |
| R1-AC6 | 缺失凭据、错误地域/模型、网络/权限/设备失败和过载均可见，无静默切换；默认无录音、字幕保存及敏感日志 | AC-08、AC-11 |

真实云验收只使用用户在本机私密提供的凭据；无凭据时可完成夹具与纯逻辑检查，但不能标为已通过真实云验收。英语/日语等能力按实际结果单独记录，首条中文链路不自动声明它们已支持。全产品 60 分钟和正式质量/性能门槛属于 R5，不替代本轮识别对照与资源检查。

## 不包含

系统音频运行接入、本地模型、翻译、Windows 10/Linux/macOS 支持、托盘/穿透、自动重连、远程 server/client、发行安装器与更新。保留这些目标及既有代码，不在 R1 增加对应运行承诺。
